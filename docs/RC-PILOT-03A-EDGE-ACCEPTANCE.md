# RC-PILOT-03A · Edge 实机验收清单（待执行）

> 本文是验收准备，不是实机验收报告。GitHub Chromium E2E 不能替代用户的 Edge 环境。
> Issue #101 继续保持 OPEN，直到实机证据、独立审计和剩余问题闭环。

## 基线

- 记录 Windows / Microsoft Edge 版本、扩展 Git HEAD、构建制品 ID、日期与时区。
- 测试页使用公开题目或测试账号，不记录 API 密钥、验证码、Cookie、真实作业账号。
- 优先复现历史反馈页 https://www.koolearn.com/shiti/tk-4-28-0-0-1.html；这只是历史复现地址，不宣称当前站点稳定可访问。
- 扩展可以识别、解析、填写候选结果，最终提交始终由用户手动确认执行。**禁止自动提交。**

## 验收矩阵

| 场景 | 操作 | 预期 |
|---|---|---|
| 零候选 | 公开无题页点击“当前屏识别” | 中文提示未识别到可用题目，不将 ACK 当成功 |
| 存在题目 | 含选择题、配图和滚动边界的页面点击识别 | 候选数量来自本次 UUID 完成快照，题目、选项、配图按实际精度记录 |
| Side Panel / Popup 并发 | 第一次识别未结束从另一窗口重复触发 | 第二次响应 WORK_ALREADY_RUNNING，并提示“已有识别任务正在运行” |
| Alt+W 并发 | Side Panel 执行中按 Alt+W | 不启动第二个检测，不覆盖活跃候选 |
| 识别超时 | 模拟内容接收器无响应 | 12 秒左右提示中文“等待超时”，不声称运行已取消，后续重试遵守单飞门禁 |
| 旧任务迟到 | 旧请求晚于较新的工作台代际完成 | 旧结果不能覆盖新任务 |
| SPA 导航 | 请求发出后切换 URL/路由 | 旧页面结果不能显示为新页面检测成功 |
| 权限不足 | 受限页、没有活动 HTTP(S) 页面 | 可理解中文警告，不发送到错误标签 |
| 异常路径 | 模拟候选产生后高亮失败 | 标记失败，撤回同 UUID 的伪完成状态 |
| 手动提交 | 验证填写后操作 | 不自动提交，用户核对后手动提交 |

## 实机证据包与判定

记录每个场景的 PASS / FAIL / BLOCKED、截图或脱敏录屏、Edge Console 关键报错、扩展版本和制品 SHA、测试 URL、运行元数据（requestId、runtimeInstanceId、runtimeGeneration、routeEpoch、seq），不含敏感凭据。

如 Edge 实机尚未操作，统一记录 `EDGE_LIVE_PENDING`，不得把 Chromium CI 通过写成 Edge 实机通过。超时不会终止正在运行的内容脚本；如果持续无响应，应在受控环境中重载页面或重新打开会话。Issue #104 的连接与传输问题仍独立追踪。
